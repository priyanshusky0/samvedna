What this is

SAMVEDNA collects live, open data on fires, earthquakes, weather and natural events for {{ cfg.states|length }} states of southern and western India, plus Indian news coverage of those hazards. It cleans and stores the data, flags unusual activity with simple, explainable statistics, and puts everything on one map-centred dashboard to support Humanitarian Assistance & Disaster Relief (HADR) planning. It is an independent student project.

States: {{ cfg.states|join(", ") }}. Bounding box (W, S, E, N): {{ cfg.bbox|join(", ") }}.

Data sources

  • NASA FIRMS: VIIRS active-fire detections (NOAA-20, Suomi-NPP) plus the public yearly India archive for a seasonal baseline.
  • USGS FDSN: earthquakes M ≥ {{ cfg.usgs_min_magnitude }}.
  • Open-Meteo: daily rainfall, max/min temperature and wind at each state capital (ERA5 archive + forecast).
  • NASA EONET: curated natural events (floods, storms, wildfires…).
  • GDELT DOC 2.0: Indian news articles and daily volume/tone timelines for four hazard queries.

All sources are public and free to use with attribution. Requests are rate-limited (GDELT ≥ {{ cfg.gdelt_min_interval_s|int }} s apart, slowing down automatically after HTTP 429), cached for {{ (cfg.cache_ttl_s/60)|int }} min, sent with a project User-Agent, and every raw response is archived for audit. No personal data is collected.

Cleaning rules

  • All timestamps converted to Asia/Kolkata (IST).
  • Rows outside the bounding box or the selected state polygons are rejected (offshore points within ~25 km go to the nearest state).
  • FIRMS: “low” confidence detections dropped; detections by different satellites within {{ cfg.firms_dedup_distance_m|int }} m and {{ cfg.firms_dedup_minutes }} min collapsed to the most confident one; static industrial sources dropped.
  • GDELT: duplicate URLs and near-duplicate headlines (normalised-title hash) removed; articles whose headline names none of the hazard's terms are dropped as off-topic.
  • Range checks (magnitude ≥ 0, rainfall ≥ 0, plausible temperatures). Missing values stay missing; nothing is silently filled.
  • Rejected-row counts per reason are stored with each fetch (see Data health).

Anomaly detection

For every state and metric, today's value is compared with the previous {{ cfg.anomaly_window_days }} days (today excluded):

zt = (xt − mean(xt−{{ cfg.anomaly_window_days }} … xt−1)) / sd(xt−{{ cfg.anomaly_window_days }} … xt−1)

z ≥ {{ cfg.z_medium }} is medium, z ≥ {{ cfg.z_high }} is high. To avoid alerts on tiny numbers (one quake after a quiet month), each metric also has a minimum absolute value. Temperature series (five years of history) also get an STL seasonal decomposition; residuals more than {{ cfg.stl_resid_z }} robust standard deviations (1.4826 × MAD) above the seasonal expectation are flagged. Fire counts are also compared with the same ±15 days one year earlier (Suomi-NPP only), which works even without 30 days of recent history.

Trends, correlation and seasonality

Mann-Kendall on complete weeks with Sen's slope as the robust rate of change: the Seasonal variant (each week compared only with the same week in other years) for the 5-year weather series, and the Hamed-Rao variant (autocorrelation-corrected) on the last 52 weeks for shorter series. Spearman rank correlation between daily hazard signals and GDELT news volume at lags 0–{{ cfg.max_lag_days }} days. The seasonal table compares this month so far with the same calendar days last year.

NLP

TF-IDF (unigrams + bigrams, custom stop-words) gives each hazard's keywords overall and per week. NMF ({{ cfg.nlp_topics }} components) on the same matrix finds topic clusters, shown with their top terms and most typical headlines. Tone uses GDELT's document tone, plus VADER sentiment on headlines. Headlines are tagged to a state when they name the state or one of its major cities.

Limitations

  • GDELT's DOC API only covers about the last three months and is strongly rate-limited.
  • Satellites pass over a point only a few times a day; clouds and smoke hide fires.
  • Headline geotagging misses articles that name only a district or village, and can mis-tag shared names.
  • One weather point per state cannot represent a whole state's rainfall.
  • Without a FIRMS MAP_KEY only the last 7 days of near-real-time fire data can be fetched.

Full details are in report/report.md. Interactive API documentation: /docs.
